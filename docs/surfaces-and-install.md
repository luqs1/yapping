## ChatGPT per plan

Key facts:
- **Work vs Chat.** On the web, the panel and sidebar extensions exist only in **Work**, "excluding classic ChatGPT" [F12]. MCP Events run only in Work chats (web, desktop Cloud) and dots [F19].
- **Custom MCP servers.** These can be added on the **web only**, at chatgpt.com/plugins > + > Add custom MCP server [F20,F21].
- **`pip`.** Not supported anywhere in ChatGPT [F12].

**Install steps.**
- **Listed:** Plugins > search "yapping" > Install > Connect (OAuth) > in a Work chat, open the sidebar app [F21].
- **Unlisted on Plus/Pro:** Settings > Security > Developer mode on (if "Add custom MCP server" is missing). Then Plugins > **+** > Add custom MCP server > name + URL > OAuth > tick "I understand" > Create as a plugin > Install > in a **Work** chat type `@yapping` [F20,F26].
- **Directory submission:** a verified developer identity, domain verification, a stable public HTTPS endpoint, review, and an optional country allow-list [F27]. Unofficial bridges are rejected [F, prior doc].

**What our server needs (every chat host).**
- A public HTTPS Streamable HTTP endpoint at `/mcp`.
- OAuth 2.1 + PKCE with protected-resource metadata.
- **CIMD first, DCR fallback** (Claude, ChatGPT and Codex all support both).
- Refresh tokens: advertise `offline_access`, or ChatGPT users must re-auth [F20].
- For Events: Standard Webhooks signing, a persistent subscription store, and SSRF-safe HTTPS callbacks [F19].

## Open questions

1. **Plus write tools.** Can Plus run destructive custom-MCP tools? The help center and the pricing page disagree (help center updated about 2026-10-27). Test on a real Plus account.
2. **Chat-mode plugins.** Do installed plugins work in plain **Chat**? Codex docs say plugins aren't in Chat or mobile [F9]. The help center says the directory is on web, desktop and mobile [F21].
3. **Desktop extensions.** Do global and thread entrypoints show in the desktop app's **Chat** view and for Free/Go, or only in Work and Codex?
4. **Codex CLI future.** Will it render MCP Apps, or get a command-backed status line (#17827)? Until then, ship a tmux pane plus hooks [I].
5. **Remote `wss:`.** Does a remote `wss://relay.yapping…` work from the ChatGPT web widget? Desktop only blocks loopback.
6. **Free/Go reach.** Is ChatGPT Sites hosting ("any plan") a viable path for Free/Go users to add our app [F21]?
7. **Claude docking.** Will claude.ai or Cowork ever dock an MCP App? (The desktop app's side panel is for artifacts and files [I].)
